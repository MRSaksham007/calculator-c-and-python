# 🧮 Calculator — C, Python & Web

A simple calculator project implemented in **C, Python, HTML, CSS, and JavaScript**.
The project demonstrates the same core calculator functionality across different programming languages and includes an interactive web-based frontend.

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal number support
* 🌐 Interactive web-based calculator
* 💻 Command-line calculator in C
* 🐍 Command-line calculator in Python
* 📱 Responsive and user-friendly frontend

## 🛠️ Technologies Used

| Technology | Purpose                  |
| ---------- | ------------------------ |
| C          | Command-line calculator  |
| Python     | Command-line calculator  |
| HTML5      | Webpage structure        |
| CSS3       | Styling and layout       |
| JavaScript | Calculator functionality |

## 💻 C Version

The C implementation provides a basic command-line calculator using:

* Variables
* User input
* `switch` statements
* Arithmetic operators
* Conditional statements

### Run the C version

Using GCC:

```bash
gcc C/calculator.c -o calculator
```

Then run:

```bash
./calculator
```

On Windows:

```bash
calculator.exe
```

## 🐍 Python Version

The Python implementation provides the same basic calculator operations through the terminal.

### Run the Python version

```bash
python Python/calculator.py
```

## 🌐 Web Version

The web version provides an interactive graphical calculator using:

* HTML for structure
* CSS for the interface
* JavaScript for calculations and user interaction

### Run the web version

Simply open:

```text
index.html
```

in any modern web browser.

No additional dependencies or installation are required.
